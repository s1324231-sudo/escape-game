ひらけ、
密室。

気になるものを調べて、謎を解く。
3つの謎を解いて、秘密の出口を見つけよう。

脱出ゲームを作る

遊び方
  1. 舞台・難易度・雰囲気を選び、「AIでゲームを作る」を押します。
  2. 各部屋で2つの手がかりを調べ、3つの選択肢から答えを選びます。
  3. 正解すると次の部屋へ進めます。3部屋の謎を解いたら脱出成功です。

    調べる

    扉の鍵

    手がかりを2つ調べると、答えを選べます。

    ✦

      作品について
      
    舞台・難易度・雰囲気を generic-webapi に送り、OpenAI API に3部屋分の謎と手がかりをJSONで作らせます。JSON.parse() で読み取ったデータを使って画面を描き、正解したときだけ次の部屋に進めます。ゲームのJSONは脱出後に確認できます。
    
      
    扉のイラストはCSSで制作しました。
